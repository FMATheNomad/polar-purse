# PolarPurse

![PolarPurse](screenshot/Screenshot_Landingpage.png)

PolarPurse adalah platform kalkulator keuangan yang membantu Anda menghitung alokasi pendapatan untuk menabung, investasi, atau beramal. Dilengkapi berbagai kalkulator bisnis seperti BEP, laba rugi, pajak, dan investasi.

## Fitur

- **Kalkulator Alokasi Pendapatan** — Hitung persentase pendapatan untuk tabungan/investasi atau amal
- **Kalkulator Keuangan Bisnis** — Hitung keuntungan bulanan
- **Kalkulator Break Even Point** — Hitung titik impas bisnis
- **Kalkulator Laba Rugi** — Hitung laba/rugi bisnis
- **Kalkulator Investasi** — Proyeksikan nilai investasi
- **Kalkulator Pajak Bisnis** — Hitung pajak penghasilan

## Teknologi

- **Backend:** Python (Flask)
- **Frontend:** Tailwind CSS, JavaScript (Vanilla)
- **API:** REST JSON

## Cara Menjalankan

```bash
pip install -r requirements.txt
python app.py
```

Buka `http://localhost:5000` di browser.
